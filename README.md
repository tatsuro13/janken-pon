# ジャンケンマン フィーバー（ブラウザ版）

駄菓子屋やデパート屋上の定番メダルゲーム、サンワイズ「ジャンケンマン フィーバー」（1987年）をブラウザで遊べるように再現したファンメイド作品です。メーカーとは関係ありません。

## あそびかた

`index.html` をブラウザで開くだけで遊べます（ビルド不要）。

1. 「10円を入れる」か「メダルを入れる」（筐体の投入口をクリックしても可）
2. 「じゃーん、けーん」の声にあわせて グー・チョキ・パー のボタンを押す
3. かち →「フィーバー！」でルーレットが回り、止まったマスの枚数（1・2・4・7・20）が受け皿に出る
   まけ →「ズコー」
   あいこ →「あーいこーで」→ もう一度ボタンで「しょっ！」
4. 受け皿をクリックすると、出たメダルを手持ちに移せる

キー操作: `1` グー / `2` チョキ / `3` パー / `Space` コイン投入 / `Y` 10円 / `M` メダル / `T` 受け皿からとる

盤面左下のカギ穴を押すと店員メニュー（出やすさの設定 1〜6、ホッパー補充、データリセット）が開きます。

## 再現したところ

- 盤面: 黄色地に虹のアーチ、左右の「かち」、左下「まけ」、右下「あいこ」のランプ、12マスのルーレット（12時から時計回りに 4・7・2・7・4・2・20・1・2・4・7・2）
- 中央の赤い LED ドットの手、上の青い回転灯、10円とメダルの投入口、操作パネル、受け皿
- 勝ち負けはコインを入れた瞬間に決まる（噂の仕様）。配当はほとんど 1 か 2
- 払い出し用のホッパーが空になると「係員をおよび下さい」ランプが点く

## 声の音源を差し替える

`sounds/` フォルダに音声ファイル（mp3 / m4a / wav / ogg）を置き、`sounds/voices.js` にファイル名を書くと、その声はファイルの音で鳴ります。

```js
window.JKM_VOICE_FILES = {
  jan: 'jan.mp3',   // 「じゃーん、けーん」
  pon: 'pon.mp3',   // 「ぽん！」
  // 空欄の声は音声合成のまま
};
```

- 「じゃーん、けーん」と「ぽん！」は鳴るタイミングが違うので、別々のファイルに分けてください
- 「ズコー」「フィーバー！」のファイルを置くと、代わりに鳴らしていた合成の効果音は止まります
- 読み込めた数は店員メニューの「読み込んだ声の音源」で確認できます
- 実機の声はメーカーの著作物です。自分で用意した音源は手元で遊ぶ範囲にとどめ、公開・配布しないでください

ファイルを置かない声は、端末の日本語音声合成で鳴ります。日本語の音声がない端末では、ピコピコ音が代わりに鳴ります。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 筐体と情報パネルのマークアップ |
| `css/style.css` | 筐体・パネル・画面レイアウトの見た目 |
| `js/hand.js` | LED の手（グー・チョキ・パー）の形 |
| `js/panel.js` | 盤面 SVG の組み立てとランプ制御 |
| `js/sound.js` | 効果音（Web Audio）と声（音声合成） |
| `js/game.js` | ゲーム進行・確率・保存（localStorage） |
| `sounds/voices.js` | 声の音源ファイルの指定（空欄なら音声合成） |
